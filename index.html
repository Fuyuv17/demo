Kết Nối Google Maps API

Dự án NCKH Đại Học Giao Thông Vận Tải

Bản đồ Google Maps đã được kết nối & hiển thị sắc nét! Hệ thống đang tải trực tiếp bản đồ vector độ phân giải cao của Google Maps (chuẩn tiếng Việt, hiển thị rõ Trường ĐH Giao Thông Vận Tải, Hồ Thủ Lệ, Ga Cầu Giấy như ảnh mẫu).
Khi nhập API Key, hệ thống sẽ kích hoạt thêm dịch vụ Google Places Autocomplete và Distance Matrix API.
Cách lấy Google Maps API Key miễn phí:
  1. Truy cập Google Cloud Console.
  2. Bật Maps JavaScript API và Places API.
  3. Tạo Credentials → API Key và dán vào ô bên trên.
